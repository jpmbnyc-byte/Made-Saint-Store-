# MADE SAiNT · MS-TM01 Trail Mule · Prototype 001

Technical package for one handmade pair. US men’s 12 wide (2E). Powder blue / fog grid / black.

The reference card in `reference/trail-mule-reference-card.png` is the design authority. Drawings are proportion studies for a patternmaker’s review. They are not measured patterns and they are not production files.

**PROVISIONAL — PHYSICAL VALIDATION REQUIRED** on every sheet.

## Contents

| Path | What it is |
| --- | --- |
| `drawings/sheet-01-orthographic.svg` through `sheet-08-sequence.svg` | Editable A3 sheets |
| `drawings/package.html` | All eight sheets, for print |

Regenerate the sheets with `python3 generate.py` from this directory.

No outsole brand is selected. The Saint Michael woodcut is not redrawn here. The wordmark on the sheets is a placement stand-in: MADE / SAiNT, lowercase i, to be replaced by the founder file.
